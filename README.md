# Project-Management-PowerBI
A Project Management Dashboard Created using Power BI
- **Objective:** Built an interactive Power BI dashboard to give management a single view of project progress, budget, billing, and risk across 1,836 projects, replacing the need to check multiple reports.
- **What I did:** Cleaned and modeled the project data, created DAX measures (completion %, financial progress %, bill clearance %), and designed KPI cards, donut, bar, area, and funnel charts with Financial/Physical/Progress toggle buttons.
- **Progress insight:** Only 37 of 1,836 projects (2.02%) are completed and 963 have not started, while financial progress is 24.80% of the 34,865M awarded amount, showing a large pipeline still to execute.
- **Pipeline insight:** The funnel shows 1,834 projects approved (AA) but only 344 completed (19.2%), with the biggest drop-off between awarding, starting, and completion. 1,271 projects (about 69%) are small-budget projects under 1 Cr.
- **Risk and billing insight:** Natural risks are the largest category (41.6% of risks), followed by contract risks, and bills of 965.36 Cr show 864.66 Cr approved with a 100.70 Cr balance, pointing to where management should focus.
